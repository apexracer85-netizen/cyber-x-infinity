CYBERX — START HERE

HOSTED APP
1. Open https://apexracer85-netizen.github.io/cyber-x-infinity/ (after GitHub Pages is enabled).
2. Sign in at the single Index login screen.
3. Normal accounts open the Zero Trust Command Centre.
4. Approved owner/developer accounts open the private Developer Control Centre.

LOCAL APP
1. Download and extract the full CyberX ZIP.
2. Keep the complete CyberX-Open-Me folder together.
3. Double-click Index/Start-CyberX-Localhost.bat on Windows (Python 3 required).
4. The launcher opens Index/index.html through localhost.

MODULES
- Command-Centre.html: Zero Trust operations dashboard.
- Index/Code-Library.html: searchable code library.
- Index/Code-Studio.html: editor and isolated browser execution for JavaScript/HTML/CSS.
- Index/Device-Security-Lab.html: device selection and safe offline simulations.
- Index/Developer-Console.html: private owner analytics and library synchronization.
